Misión del Proyecto:

Desarrollar un sitio web completo implementando estructuras semánticas en HTML5, hojas de estilo en cascada (CSS3) para un diseño adaptable, y lógica de interactividad utilizando JavaScript puro (Vanilla JS).

Este sistema simula el funcionamiento frontend de una tienda en línea enfocada en la botánica y el cuidado de las plantas de interior.
